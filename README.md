# rhino-in-space

A client for [cyberspace.online](https://cyberspace.online/), the text-only
social network, running on ESP32-S3 handhelds:

- Elecrow CrowPanel Advance 3.5" (480×320, touch)
- Elecrow CrowPanel Advance 5.0" (800×480, touch)
- LilyGo T-Deck Plus (320×240, touch, keyboard, trackball)

Hardware support comes from [camillia-mt](https://github.com/oumike/camillia-mt).

Status: research. See [docs/RESEARCH.md](docs/RESEARCH.md) for the API, the
hardware, the proposed architecture and the milestones.

This is a personal client operated by a person, as the Cyberspace API terms
allow. It does no scraping, runs no bots and sends no content to AI systems.
